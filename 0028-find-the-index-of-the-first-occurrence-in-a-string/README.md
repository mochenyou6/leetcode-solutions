problem:给你两个字符串 haystack 和 needle ，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回  -1 。

  在一个字符串里面查找另一个字符串，是典型的字符串问题，可以用BF算法或者KMP算法，但是由于BF算法的时间复杂度通常高于KMP算法，效率低下，所以这里采用KMP算法。
这是我在学习完KMP算法之后，第一次尝试去用KMP算法的思想去解决问题。

我遇到的第一个问题：
  我并没有尝试去求两个字符指针所指字符的长度，而是直接想的是利用指针指向末尾的‘\0’作为结束的标志，这样也可以，但是代码不够直观。返回已匹配时模式串在主串里的下标时，不容易理解。

第二个问题：
  我在写get_next函数，进入while循环时，我使用了if进行正向判断，导致我在写else的时候，不断往里面用if打补丁以此来保证我的代码按照我预定的方向进行。但是我在else里面不断套if-else语句，我发现这个代码还是会有漏洞，因为要反反复复让j指针回退，但是进入else再进入if-else，就只能往下走，一直走到头才能循环，此时，为了在单向执行的语句里实现反反复复回退的目的，我就只能反反复复使用if-else语句，这是极其麻烦的，或许能再嵌套循环语句，但这样的时间复杂度又太高了，所以我换了一种方法。
  关键点：当字符串的下标不是从1开始，j就没有了缓冲区域，就要对next[0]和j==0进行特殊判断，避免进入死循环。
  i是不断向前的，j是反反复复回退的，if-else语句类似于树型结构只执行一次，while语句才会反反复复执行多次。只有在不等于的条件下，j才会回退。如果将放在else语句里面，前面是已经执行过的if语句，那么此时的j就已经进入树型结构里，只能往下走，达不到反反复复执行的条件。所以，第一个if语句用反向判断，让j在一直循环直到达到条件，再进入下一步，接下来就会简单很多。
